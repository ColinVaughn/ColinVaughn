## Selected projects

### [Synaptic](https://github.com/ColinVaughn/Synaptic)

Auditable code intelligence for AI agents. Synaptic compiles repositories into a persistent knowledge graph across 30+ languages with tree-sitter, then exposes dependency tracing, change-impact analysis, affected-test selection, structural search, and refactor verification over MCP.

`Rust` `tree-sitter` `MCP` `Static analysis`

### [Tessellate](https://github.com/ColinVaughn/Tessellate)

A NeoForge performance mod for Minecraft 1.21.1 that separates distant loaded areas into independently scheduled regions. Parallel region ticking reduced median global tick time by 61.2% in its documented four-region benchmark while all regions maintained 20 TPS.

`Java` `NeoForge` `Concurrency` `Performance engineering`

### [Tunnely](https://tunnely.org)

A Rust VPN platform with a Tauri and SolidJS desktop client, WireGuard connectivity, multi-relay routing, QUIC/HTTP3 obfuscation, and a Next.js control plane. Its relay network spans 10 nodes across four continents.

`Rust` `WireGuard` `Tauri` `SolidJS` `Next.js`

### [A11yCore](https://a11ycore.org)

A full-stack accessibility platform for real-time WCAG 2.2 scanning and browser-side remediation. It has processed more than 10,000 scans for 500+ users and includes a lightweight ESM plugin with 76+ DOM accessibility features.

`TypeScript` `React` `Supabase` `PostgreSQL` `Puppeteer`

### [Omni](https://github.com/Omni-App-AI/Omni) - discontinued

A privacy-first desktop AI agent platform built with Rust, Tauri, React, and sandboxed WebAssembly extensions. It included multi-provider LLM orchestration, a deny-by-default plugin runtime, content-safety controls, and messaging integrations.

`Rust` `Tauri` `React` `WebAssembly` `LLM systems`

> Omni is no longer under active development. The repository remains available as a technical reference.
